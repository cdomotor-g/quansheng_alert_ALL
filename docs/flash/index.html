Radio installer

Puts the ALERT flood-warning receiver firmware on your Quansheng radio. It backs your radio up first, then does the rest itself. There is nothing to download, unzip or compile.

Serial port held by this page

This browser can’t talk to the radio

Installing needs Web Serial, which Chrome, Edge and other Chromium browsers have, but only on a desktop or laptop (Windows, macOS, Linux or ChromeOS).

Open this same page in Chrome or Edge on a computer and you’re away. The setup guide works anywhere, so you can read ahead on this device.

1 Which radio do you have?

Take the battery off and read the label. The two kinds look almost the same from the front but have different chips inside, and each needs its own firmware. How to tell them apart.

Not sure? Pick the one you think it is. Before writing anything the installer reads the radio’s bootloader version, which tells the two apart for certain, and it stops if the firmware doesn’t match.

2 Pick the firmware

Both builds are the same program. They differ only in which region’s station names are stored in the radio, because there is only room for about 6 KB of names. Stations outside the list still decode — you just see the number instead of the name.

One build covers every V3 / UV-K1. It has the South-East Queensland networks’ station names built in, and you can load any other region’s names over USB later (see the guide). Stations outside the list still decode — you just see the number instead of the name.

Pick your radio in step 1 first.

Use my own firmware file instead

For a build you made yourself, or for going back to stock or another custom firmware. Both .packed.bin and raw .bin files work. The file is checked before anything is sent to the radio, including that it was built for the chip in the radio you picked in step 1.

3 Plug in and connect

You need the two-pin programming cable — the same one Baofeng radios use, with a 3.5 mm and a 2.5 mm plug at one end and USB at the other. This radio’s USB-C socket will not do: it only charges the battery. Many kits include a programming cable — check the box. Otherwise any “Kenwood 2-pin / K1 USB programming cable” works (prefer one that says CH340). Got a USB–TTL adapter and a soldering iron? Build one instead.

  1. Plug the programming cable into the radio’s side socket and into a USB port. Push both plugs in firmly — a half-seated plug is the most common reason this fails.
  2. Switch the radio on normally (just turn the volume knob).
  3. Press Connect and choose the cable from the list your browser shows. It is usually called USB-SERIAL CH340, USB Serial or Prolific.

Use a USB-C data cable into the radio’s own USB-C socket — the V3 and UV-K1 have a real USB port. The cable must carry data: a charge-only cable (often the thin one that came in the box) shows nothing at all. The two-pin programming cable works too, if you have one.

  1. Plug the USB-C cable into the radio and the computer.
  2. Switch the radio on normally (just turn the volume knob).
  3. Press Connect and choose the radio from the list your browser shows. On USB-C it shows up as a USB Serial Device or similar (with the two-pin cable: USB-SERIAL CH340).

The list is empty, or the radio isn’t answering
  • Nothing in the list: the cable’s driver isn’t installed. Most cables use a CH340 chip — install the CH340 driver, unplug and re-plug the cable, then try again.
  • Nothing in the list: try another USB-C cable — charge-only cables are very common. The radio must be switched on. Windows 10 and 11, macOS and Linux need no driver for the radio’s own USB port.
  • Port appears but the radio doesn’t answer: push the plugs in harder, make sure the radio is switched on, and close any other program that might hold the port open (CHIRP, UV Studio, a serial terminal, alertterm).
  • The Toolbox below has a Check the cable test that works out which side the problem is on.

4 Back up your radio

This saves your radio’s factory calibration, every channel and all your settings. The calibration is unique to your radio and can’t be downloaded from anywhere, so we take a copy before changing anything. It takes about ten seconds and doesn’t alter the radio. The radio must be switched on normally.

On a V3 / UV-K1 the calibration lives on a separate memory chip that installing never touches, so this copy is a safety net. If your radio still has its stock firmware this step may not work, because stock firmware lays its memory out differently — that’s fine: tick “skip this”, and take the backup from the last step once the new firmware is running.

Worth knowing: the firmware itself can’t be read out of the radio — the bootloader has no “read” command, so no tool can do it. That’s not a problem: firmware is replaceable in a minute, whereas your calibration is not. The backup below is the one that matters.

5 Install the firmware

Now put the radio into bootloader mode (also called flash mode or DFU mode).

  1. Switch the radio off. If you are on USB-C, the port disappears now and the bar at the top goes away — that is normal.
  2. Hold the PTT button (the big one on the side) and, while holding it, switch the radio on with the volume knob.
  3. The screen stays blank and the torch LED at the top lights. That’s bootloader mode. Let go of PTT.
  4. Press Install firmware now. On USB-C your browser asks for the port again — pick the radio. In bootloader mode it can appear under a new name or number; that is expected. Leave the cable plugged in the whole time.

Install it anyway

Only if you are certain the check is wrong. On incompatible hardware this produces a radio that will not start — it stays re-flashable in bootloader mode, but it will not boot until the right firmware is put on it. Type FLASH ANYWAY to unlock.

Nothing here can permanently damage the radio. The bootloader lives in a separate part of the chip that is never written, so if an install is interrupted the radio still starts in bootloader mode and you simply do it again.

✓ Done

Back up the calibration now

With the new firmware running, its memory layout is known, so this is the backup that counts (it’s the one the F4HWN project recommends too). Keep the file with the radio’s serial number in its name.

Start receiving

  1. The ALERT receiver starts by itself about five seconds after the radio is switched on. To open it yourself, press MENU, scroll to the last item, AlrtRx (the list wraps round, so going back one from the first item gets you there), then press MENU twice. EXIT leaves it.
  2. It listens on whatever frequency the radio is on. If that is outside 130–174 MHz it tunes itself to 151.500 MHz. To change it: MENU inside the app, then MENU down to FREQ MHz, and ▲ / ▼.
  3. The first time, it counts down SETTLING, runs a short CENSUS (a few seconds; you may hear two tones) to find its audio path, then shows WAITING. Leave it there — readings appear as stations transmit.

Set it up, once

  1. Menu → Voice → English, so it reads the readings out.
  2. Menu → Sql: start at 0.0 and raise it in tenths until the static just goes quiet.
  3. Tune to 151.500 MHz, FM.
  4. Press F then 0 to open the ALERT receiver.

This build has not decoded a real ALERT transmission yet. Read what that means for a UV-K5 in the guide.

Everything else — what the screens show, the keys, logging to a computer, and what to do if nothing decodes — is in the setup guide.

Toolbox

What is my radio running?

Asks the radio which firmware it has, or, in bootloader mode, which bootloader — which settles V1 versus V3 for certain.

Check the cable

For when the radio “does not answer”. Identifies the adapter, listens to the line, asks the radio a harmless question, and only if bytes are arriving that make no sense tries every other baud rate — then says which side to look at. It never writes to the radio. Best with the radio in bootloader mode (off, hold PTT, on): it then talks on its own, so the check proves wiring, polarity and rate at once.
